# 觉醒伪神 · 世界观设定总纲

> 用途：世界观的唯一权威文本。前端「万神大厅」的数据源 `src/data/loreData.js` 与本文件一一对应，改设定先改这里，再同步数据文件。
>
> 分类原则：能把同一层级的条目收进同一卷的，就单独成卷；跨阶段才解锁的（如神印谱），单独标注解锁条件。

---

## 一、修为等级（十一阶 · 一条主梯）

从凡人到真神，是一条不可跳级的主线阶梯。

| 阶位 | 名称 | 说明 |
|---|---|---|
| 1 | 凡人 | 未觉醒，未铸神印 |
| 2 | 一印 | 烙下第一枚神印，正式踏入修行 |
| 3 | 二印 | 双印共鸣，可施展基础神技 |
| 4 | 三印 | 三印之躯，一镇之地可称强者 |
| 5 | 四印 | 四印圆满，门阀权贵的入场门槛 |
| 6 | 五印 | 五印威压，足以坐镇一城 |
| 7 | 六印 | 六印强者，神堂名录在册 |
| 8 | 七印 | 七印之境，寻常岁月难以企及 |
| 9 | **八印【天锁八印】** | 肉身即神狱，凡躯锁天门；修行者的天花板 |
| 10 | 半神 | 半步神域，只差最后一场造化 |
| 11 | **真神（自封之神）** | 不受神堂册封，自己给自己的神格 |

**体系要点**
- 一至八印属"印阶"，神印数量即实力刻度，神堂以此册封与统计。
- 八印称"天锁"，是凡躯的极限，也是神堂最能容忍的顶点。
- 半神→真神一步，神堂不给路，只能自封——这正是书名与男主一路的落点。

## 二、元素与异能体系

### 2.1 普通元素（六系 · 一大类）

| 元素 | 定位 | 战斗特征 |
|---|---|---|
| 火 | 强攻 | 焚尽，最狂暴的进攻元素 |
| 冰 | 控制 | 凝滞，冻结灵能与血肉 |
| 雷 | 爆发 | 霹雳，速度与毁灭并存 |
| 风 | 机动 | 疾行、切割，身法与锋刃 |
| 土 | 防御 | 厚重，大地之力筑墙 |
| 水 | 续航 | 润泽，绵长不绝的韧性 |

### 2.2 特殊系（六路 · 另一大类）

| 系别 | 代表能力 | 归属 | 说明 |
|---|---|---|---|
| 光明系 | 神罚、神赐 | 神堂 / 神子 | 诸神直接赐下，正统中的正统 |
| 黑暗 / 恶鬼系 | 噬魂、鬼爪 | 恶鬼之牙公会 | 阴冷诡谲，神堂明令禁绝 |
| 兽系 | 兽变、肉身狂暴 | 散修 / 公会在册 | 以蛮力碾碎神技，越痛越强 |
| 精神系 | 精神冲击、意念操控 | 无固定归属 | 杀人于无形，最难防御 |
| 空间系 | 位移、空间斩 | 稀有 | 万里之外取人首级，灵能消耗极大 |
| 植物系 | 控草木、束缚、治疗 | 无固定归属 | 战场上最被低估的一系 |

### 2.3 男主例外

男主【伪神】**不属于任何常规元素**，作战不靠元素相性，靠神魔权柄（解析 · 掠夺 · 改写）。

## 三、神印颜色与属性（觉醒后解锁）

> **解锁规则**：此卷需觉醒（登临神位 / 铸印封神）后方可翻阅；未觉醒者在万神大厅只能看到封印态。

| 印色 | 属性 | 归属 | 说明 |
|---|---|---|---|
| 金 / 白印 | 光明 | 神堂 · 神子 | 正统神赐，神格凭证，生来高人一等 |
| 绿印 | 生命 | 生命系修士 | 治愈、植物、束缚 |
| 蓝印 | 水 · 冰 · 精神 | 三系同源 | 静水流深，攻守兼备 |
| **红印** | 魔 · 恶鬼 | **男主专属** | 野生禁忌，只能用野生红印；神弃者唯一的路 |
| 黑印 | 深渊 · 古神 | 禁忌者 | 古神禁忌之力，印成之日神堂缉杀令随之而来 |

**体系要点**
- 神堂只认金白二色，其余一律称"野种"。
- 神弃者无法镶嵌正统神印，只能以野生红印为凭——红印是男主的"资格证"，也是他的骂名。

## 四、男主 · 伪神核心

**天赋**：SSS 级【伪神】· 神弃者 · 无法镶嵌正统神印

### 4.1 神魔四变

| 变化 | 权柄来源 | 战斗方式 |
|---|---|---|
| 神变 | 借诸神权柄 | 神罚类攻击，以神之名审判神 |
| 魔变 | 禁忌魔力 | 破坏力极强，代价与锋芒并存 |
| 兽变 | 肉身狂暴 | 刚虎吞天，一息撕碎神印护壁 |
| 鬼变 | 噬魂鬼爪 | 直取灵魂，专打神印护不住的地方 |

### 4.2 核心能力

解析 → 掠夺 → 改写 → 升格。

- **解析**：拆解他人神印结构，看清命门
- **掠夺**：夺走他人的权柄与神技
- **改写**：篡改神印规则，让神技为己所用
- **神魔同流**：四种变化可交叠，亦可互相污染
- **打破神明规则** · **自我封神**
